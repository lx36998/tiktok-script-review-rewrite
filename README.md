# TikTok 短视频文案审核仿写 Skill

根据骨肉皮模型与 4T 四力审核 TikTok 原视频文案，生成一版中英文双语简介、话题和口播稿。口播长度会与原稿比较，要求严格小于原稿的 110%。

支持 Skill 的 AI 平台可安装本仓库，不支持 Skill 的平台可通过上传或粘贴说明使用。

## 平台支持导入 Skill

导入本仓库整个文件夹，并保留目录结构。具体安装入口和路径由各平台决定。导入后提供视频口播稿和视频简介，要求使用该技能审核和仿写。

## 平台支持上传文件或粘贴提示词

把 `SKILL.md` 上传给 AI，或复制其中的完整内容到对话中，再附上原口播稿和视频简介，要求按文件中的步骤输出。也可以通过 GitHub 的 Code → Download ZIP 下载整个仓库，再上传给支持读取压缩包的平台。

## 输入示例

请按提供的 TikTok 文案审核仿写技能处理以下内容。

原视频简介：
【粘贴原简介及话题】

原视频口播稿：
【粘贴完整原稿】

产品、目标人群或表达风格（可选）：
【填写已知信息】

## 口播长度检查

技能要求仿写稿严格短于原口播的 110%。英文原稿默认按英文单词数计算。只有中文原稿时，原稿和中文版仿写均按汉字、英文字母和数字的字符数计算。

支持 Python 3 的环境可以用随包脚本检查，脚本只需标准库：

```bash
python3 scripts/check_length.py 原稿.txt 仿写稿.txt
```

中文字符口径在命令末尾加 `--unit characters`。两个文件只放各自的完整口播稿。

AI 平台具备代码运行或字数统计能力时，也可按技能中定义的相同口径检查。若平台无法运行或准确计数，应要求 AI 说明长度尚未验证。
